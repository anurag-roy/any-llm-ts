## `completion(params)`

```ts
function completion(
  params: DirectCompletionParams & { stream?: false },
): Promise<ChatCompletion>;

function completion(
  params: DirectCompletionParams & { stream: true },
): Promise<AsyncIterable<ChatCompletionChunk>>;
```

## `responses(params)`

```ts
function responses(
  params: DirectResponsesParams & { stream?: false },
): Promise<unknown>;

function responses(
  params: DirectResponsesParams & { stream: true },
): Promise<AsyncIterable<unknown>>;
```

## Direct provider options

Stateless operation parameters extend the operation's common parameter type with:

For model-based operations, omit `provider` only when `model` uses `provider:model` syntax.
`listModels()` has no model from which to infer a provider, so its `provider` field is required.

`moderation()` is the exception: it defaults to `openai` when the provider is omitted.
