## Naming conventions

- Public JavaScript names use idiomatic camelCase: `imageGeneration`, `listModels`, and
  `providerOptions`.
- Wire-format fields are translated to camelCase in normalized responses.
- Provider-specific fields retain the provider's naming inside `providerOptions`, `clientOptions`,
  `raw`, and `extraContent`.
- All network operations are promise-based.
- Streams use the standard JavaScript `AsyncIterable` protocol.
